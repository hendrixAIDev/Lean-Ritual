## 4. Data & Privacy Compliance

- **Synthetic data only:** All scenes run against a disposable local `server.js` on `127.0.0.1` with a temporary `DATA_DIR` and a seeded synthetic demo account (`demo@example.com`, `小林` / `Alex`). No production database or real user data is ever accessed.
- **Mocked AI:** All `POST /api/ai` calls are intercepted in Playwright with deterministic mock responses (`storyboard.js` / `record.js`); no external AI provider or paid API key is used.
- **Repository hygiene:** Generated MP4s, posters, contact sheets, and cached TTS weights live outside git and are excluded from production release packages (`ops/package-release.py`).
