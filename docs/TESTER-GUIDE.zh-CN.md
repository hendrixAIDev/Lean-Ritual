# 薄肌日课（Lean Ritual）内测体验指南

> **赶时间？先看 2 分钟版：** [TESTER-QUICKSTART.zh-CN.md](TESTER-QUICKSTART.zh-CN.md)

感谢帮忙测试！**薄肌日课**是一款轻量级训练、饮食与体重记录应用，底部共 5 个页面：**今天 / 饮食 / 记录 / 反馈 / 我的**。直接用浏览器打开即可，**不需要** Claude 账号、付费订阅或个人 API Key；即使服务器暂未开启 AI，也能完整手动记录。

> **重要前提（大陆测试）：** 请先**关闭 VPN、代理或加速器**，直接使用手机流量（移动/联通/电信）或日常 Wi-Fi 访问 `https://leanritual.app`。全程约 **15 分钟**。

---

## 一、接受邀请与注册

1. 打开我私发给你的**专属邀请链接**（会自动填好邀请码和邮箱；每个链接仅限受邀邮箱使用一次，**请勿转发**）。
2. 在 **「凭邀请注册」** 标签下填好称呼，设置 **至少 8 位** 的密码，点击 **「注册并发送验证邮件」**。
3. 前往邮箱查收主题为 `Lean Ritual · 验证邮箱` 的邮件，**1 小时内**点击验证链接，再回到 `https://leanritual.app` 登录。
4. **QQ / 163 邮箱提醒：**
   - 首次收信可能延迟 1–3 分钟，或进入 **「垃圾邮件 / 订阅邮件 / 广告邮件」**，请搜索 `Lean Ritual` 或 `leanritual.app`。
   - 若超过 3 分钟未收到，可在登录页点 **「重新发送验证邮件」**，并顺手把发件人加入白名单。
   - 请记下**收信耗时**及**是否进了垃圾箱**，这对我们排查邮件投递非常重要。

## 二、添加到主屏幕（建议体验）

- **iPhone（请用 Safari 打开）：** 访问 `https://leanritual.app` → 点击底部 **分享**（方框向上箭头）→ 选择 **「添加到主屏幕」** → 点击右上角 **「添加」**，之后可像 App 一样全屏打开。
- **Android（Chrome / Edge / 系统浏览器）：** 访问 `https://leanritual.app` → 点击右上角菜单 `⋮` → 选择 **「添加到主屏幕」** 或 **「安装应用」**。

## 三、15 分钟测试清单

按顺序勾选完成即可；某一步卡住时，记下**时间点**与**截图**，可继续测后面步骤：

- [ ] **1. 打开与登录：** 关闭 VPN 打开 `https://leanritual.app`，确认无浏览器证书警告；完成邀请注册、邮箱验证并登录（iPhone 可同时测主屏幕图标启动）。
- [ ] **2. 一分钟建档：** 填好性别、年龄、身高、体重、每周训练日与训练地点，点击 **「生成我的计划」** 进入主界面。
- [ ] **3. 今日打卡：** 在 **「今天」** 页的「今日打卡」填体重、步数或睡眠（至少一项），点 **「保存打卡」**，确认显示「已记录」。
- [ ] **4. 饮食拍照 + AI 估算：** 切到 **「饮食」** 页 → 选餐次 → 上传一张**非敏感食物照片**（iPhone 优先用相机实拍的 HEIC 原图；也可顺手拍一张包装营养成分表）→ 选 **「AI 估算」** 点 **「保存并 AI 估算」**（若提示服务器暂未开通 AI，改选 **「自己填」** 保存并在反馈里注明）。
- [ ] **5. 记录训练并刷新：** 回 **「今天」** 页（若当天是休息日，可在页面上方切换成任意训练日）→ 至少填写 1 组重量和次数 → 点 **「完成训练，保存」** → **刷新页面**（或关闭重开），确认训练仍在，且 **「记录」** 页能看到明细。
- [ ] **6. AI 反馈 → 采纳（只改今天）→ 撤销：** 切到 **「反馈」** 页 → 在「让 AI 看看」写一句简短感受（如「卧推时右肩有点紧，想换个动作」）点 **「提交反馈并分析」** → 出现建议后点 **「采纳」**，核对 **只改今天 / 长期调整 / 不采纳** 选项，选 **「只改今天」** 确认生效 → 再点 **「已采纳 · 撤销」**（或「撤销」）确认恢复原状（AI 未开通时可跳过并注明）。
- [ ] **7. 中英文切换：** 切到 **「我的」** 页 → 点右上角 **中文 / English** 切到英文，浏览 1–2 个页面确认显示正常，再切回「中文」。
- [ ] **8. 导出数据：** 在 **「我的」→「账号」** 点 **「导出我的记录和照片」**，确认能下载 `.ndjson` 文件。
- [ ] **9. 密码重置邮件：** 在 **「我的」→「账号」** 点 **「退出登录」** → 登录页点 **「忘记密码」** 发送邮件（主题 `Lean Ritual · 重置密码`）→ 通过邮件链接设新密码 → 确认**旧密码登录失败、新密码登录成功**。

## 五、隐私说明与删除账号

- **测试数据建议：** 请使用**真实但非敏感**的数据与食物照片（不要上传身份证件、体检报告、人脸或私密照）。数据托管于阿里云美国西部（硅谷）服务器，详情可在应用内 **「我的」→「隐私说明」**（`https://leanritual.app/privacy.html`）查看。
- **删除测试账号：** 测试结束后如不再保留数据，进入 **「我的」→「账号」→ 展开「删除账号」→ 输入密码并勾选确认 → 点击「永久删除账号」**。删除后会清除服务器上的账号、全部记录与照片且**无法恢复**（需要保留请先导出）。
