隐私说明（上线前草稿）

此应用尚未开放公测，当前供受邀测试使用。应用已部署于阿里云美国西部；邮件使用 Resend。AI 供应商、邮件处理地区与保留规则、备份位置和保留期限尚待确认；确认并更新本页后才可开放公测。

运营者

本应用由杰瑞智能技术服务部运营。支持与隐私联系邮箱：hendrix.ai.dev@gmail.com。你可以使用自己的邮箱发送邮件，无需注册 Gmail。

我们保存什么

我们保存你提供的邮箱、称呼、加密哈希形式的密码，以及登录所需的会话记录。你填写的训练、饮食、体重、身体指标、伤病说明和照片保存在自己的账号下。新上传的照片会重新编码并去除原始元数据（例如 EXIF 信息）。登录和接口请求会用到 IP 地址等必要技术信息以限制滥用。我们不需要你的 Claude 账号、订阅或个人 AI API 密钥。

数据在哪里处理

应用部署于阿里云美国西部（硅谷）服务器，应用数据存储于中国大陆以外；实际备份位置会在公测前列明。网页没有广告或分析跟踪器；登录使用必要的会话 Cookie。浏览器会按账号保留未保存的输入和训练草稿；在共享设备上请退出登录，不要保存密码。

账号邮件

验证邮箱和重置密码时，系统通过 Resend 发送邮件，邮件服务会处理收件邮箱、相关账号链接和必要的投递信息。实际处理地区、保留规则与投递情况仍需核实并在公测前补充。请勿转发验证或密码重置链接。

使用 AI 时

当你主动请求 AI 估算或反馈，相关文字、照片，或最近的训练、饮食、身体及伤病信息会从我们的服务器发送给配置的 AI 服务商。你可以选择手动记录而不调用 AI。供应商名称、处理地区及其保留规则将在上线前补充；服务商的保留规则可能与本应用不同。AI 估算可能有误，你可以修改结果。

导出和删除

在「我的」账号区可导出自己的记录和照片。导出文件为 NDJSON：每行是一个 JSON 对象，照片以 Base64 保存，便于转存和迁移。文件含私人信息，请妥善保管。

删除账号需要输入密码并确认。删除后会撤销登录并删除账号、在线记录、照片及本设备该账号的草稿；已经下载到其他设备的文件不受影响。中断的在线清理会重试。为避免旧备份恢复出已删除账号，我们保留随机账号标识和删除时间，不在该删除清单中保留健康记录、照片或密码。

备份与保留

备份用于故障恢复，可能在到期前保留已删除数据。建议的最长保留期为 30 天，但目前本地及异地保留策略尚未配置，不能承诺已经自动到期删除。上线前必须确认并实际启用保留策略；恢复旧备份时会重新应用最新删除清单。AI 服务商已接收的数据按其规则处理。

联系与更正

你可以在应用中修改自己的记录。如需处理账号、数据或隐私问题，请联系 hendrix.ai.dev@gmail.com。请勿在邮件中发送密码或 API 密钥。
